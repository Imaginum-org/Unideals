# SEO and AI-crawler setup

Unideals is a client-rendered React SPA on Vercel. Google renders JavaScript; most other crawlers don't, including:
- link previews: WhatsApp, X, LinkedIn, Slack, iMessage;
- AI assistants: ChatGPT (GPTBot, OAI-SearchBot), Perplexity, Claude.

So every page has to make sense **before** JavaScript runs. This doc covers how that works.

## Pieces

| Piece | File | What it does |
|---|---|---|
| Base HTML | `frontend/index.html` | Site-wide title, description, robots, icons, Open Graph and X cards (`og-image.jpg`, 1200×630), `Organization` + `WebSite` JSON-LD, preconnects. **No** canonical or `og:url` here; those are per page. |
| Crawlable summary | `#seo-shell` inside `#root` in `index.html` | Plain HTML describing the site: what it is, how it works, categories, campuses, safety, FAQs, links. Read by crawlers without JavaScript. With JavaScript, an inline script hides it before first paint and React replaces it on mount, so users never see it. Keep it accurate; it must describe the real product. |
| Per-page tags | `frontend/src/components/Seo.jsx`, `src/components/seo/PageSeo.jsx`, `src/components/seo/routeSeo.js` | Every public page sets its own title, description, canonical, `og:*`, `twitter:*` and optional JSON-LD. Titles and descriptions live in `ROUTE_SEO` (one place). Tags are cleared on leaving a page, so nothing leaks to the next one. |
| Listing pages, server side | `frontend/api/product-meta.js` (Vercel function), `vercel.json` rewrite `/product/:ref` | Injects the listing's title, price, description, photo, canonical, social tags, `Product` + `BreadcrumbList` JSON-LD and a readable summary into the HTML. The normal app boots on top. Cached at the edge for 10 min. If the API is down it serves the plain app; a missing or private listing gets `404` + `noindex`. |
| Listing data for it | `GET /api/product/seo/:ref` → `backend/src/services/sitemap.service.js` (`getListingSeo`) | Public facts only (title, price, condition, photos, campus, seller first name), never for Girls Corner, deleted or draft listings. Campus-agnostic so shared links preview for anyone. |
| Structured data, client side | `src/components/seo/productJsonLd.js` | One `Product`/`Offer` builder (INR price, availability, condition, seller) used by both the page and the Vercel function. |
| Sitemaps | `public/sitemap.xml` (index) → `public/sitemap-pages.xml` (static) + `/sitemap-listings.xml` | The listings sitemap is generated by the API (`backend/src/app.js`, cached 1h, up to 45k URLs, public listings only) and proxied onto `unideals.in` by `vercel.json`. |
| Crawl rules | `public/robots.txt` | Public pages open. Account, auth, chat, upload and checkout paths blocked. AI crawlers (GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, PerplexityBot, Google-Extended, Applebot) explicitly allowed. Points to the sitemap. |
| AI summary | `public/llms.txt` | Plain-text overview for AI assistants: what Unideals is, how it works, safety, campuses, categories, pricing, key pages. Keep it in sync with the product. |
| Icons | `public/favicon-16x16.png`, `favicon-32x32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `fav.svg`, `site.webmanifest` | Proper PNG sizes for browsers, iOS and installable PWA. |

## Rules of thumb
- **New public page:** add an entry to `ROUTE_SEO` and render `<PageSeo path="/your-path" />`. If it's indexable, add it to `public/sitemap-pages.xml`.
- **Private or account page:** use `AccountLayout seoTitle=…` (noindex) and add the path to `robots.txt`.
- **Never** index Girls Corner content: listings, categories and the girls-only feed stay `noindex`, out of sitemaps, and out of `/api/product/seo`.
- Social cards are cached by the platforms. After changing `og-image.jpg`, refresh them with the [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) and the [LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/).

## After deploying
1. **Google Search Console** and **Bing Webmaster Tools**: verify `unideals.in` and submit `https://unideals.in/sitemap.xml`. Bing's index also feeds ChatGPT search.
2. Spot-check raw HTML: `curl -A "GPTBot" https://unideals.in/product/<slug>` should show the listing's `<title>`, canonical and `Product` JSON-LD.
3. `SEO_API_ORIGIN`: only set this in the Vercel project if the API isn't at `https://api.unideals.in`.
